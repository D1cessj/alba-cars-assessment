# Alba Cars Take-Home Assessment

Three assignments, one repo. Each folder stands on its own with its own
README, BUILD_LOG.md, and setup instructions.

| Assignment | Folder | Live URL | Status |
|---|---|---|---|
| 1 — Creative, API-Integrated Web App | [`assignment-1-stargazing`](./assignment-1-stargazing) | _add once deployed_ | Built & tested locally |
| 2 — Data Dashboard on a Backend Service | [`assignment-2-dashboard`](./assignment-2-dashboard) | _add once deployed_ | In progress |
| 3 — n8n Automation Workflow | _n8n Cloud (see below)_ | https://saifo009.app.n8n.cloud | Built & tested |

## Assignment 1 — Nightscope

A stargazing-conditions app fusing NASA's Astronomy Picture of the Day with
live weather (Open-Meteo) into a single score, served through a Next.js
backend-for-frontend. See
[`assignment-1-stargazing/README.md`](./assignment-1-stargazing/README.md).

## Assignment 2 — Car Dealership Dashboard

A Supabase-backed inventory & sales dashboard for Alba Cars with row-level
security and server-computed analytics. See
[`assignment-2-dashboard/README.md`](./assignment-2-dashboard/README.md).

## Assignment 3 — Vehicle Recall Watcher (n8n)

An n8n workflow that checks the dealership's inventory against NHTSA's
public recall database daily, emails a digest of new recalls, and logs
every run to Google Sheets for verification. Live on n8n Cloud.
